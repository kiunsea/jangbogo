JANGBOGO — 대응 소스 안내 (Corresponding Source)
================================================================

이 배포본에 담긴 소프트웨어의 소스 코드를 받는 방법입니다.
AGPL-3.0 제6조가 요구하는 "대응 소스를 찾을 수 있는 명확한 안내"에 해당합니다.

아래 버전 값은 빌드할 때 자동으로 채워집니다. 저장소의 원본 파일에는
자리표시자만 있습니다 — 버전을 두 곳에 적지 않기 위해서입니다.


1) JANGBOGO 본체 — AGPL-3.0-or-later
----------------------------------------------------------------
  버전        : @APP_VERSION@
  소스 저장소 : https://github.com/kiunsea/jangbogo
  이 릴리스   : https://github.com/kiunsea/jangbogo/releases/tag/v@APP_VERSION@
  전체 이력   : git clone https://github.com/kiunsea/jangbogo.git

  라이선스 전문은 같은 폴더의 LICENSE 파일에 있습니다.

  AGPL-3.0 제13조 안내: 이 프로그램을 **수정**한 뒤 네트워크를 통해 다른
  사용자와 상호작용하도록 운영한다면, 그 사용자에게 수정본의 대응 소스를
  제공해야 합니다. 수정하지 않고 그대로 쓰는 경우에는 위 저장소 주소를
  알리는 것으로 충분합니다.


2) 번들 Java 런타임 (jre 폴더) — GPLv2 + Classpath Exception
----------------------------------------------------------------
  버전 : @JAVA_VERSION@

  이 폴더의 런타임은 Eclipse Temurin(OpenJDK) 배포본에서 jlink 로 필요한
  모듈만 추려 만든 것입니다. 별도 설치 없이 실행할 수 있게 하려고 함께
  담았습니다.

  소스 : https://github.com/adoptium/jdk21u
         https://adoptium.net/temurin/release-notes/
         (위 버전과 같은 태그를 고르십시오)

  각 모듈의 라이선스 전문과 제3자 고지는 jre/legal 폴더에 그대로 들어
  있습니다. Classpath Exception 덕분에 이 런타임 위에서 도는 프로그램이
  GPL 을 따를 의무는 생기지 않습니다.


3) 제3자 라이브러리
----------------------------------------------------------------
  애플리케이션 JAR 안(BOOT-INF/lib)에 각 라이브러리가 원본 JAR 그대로
  들어 있습니다. 압축을 풀면 개별 파일로 꺼낼 수 있습니다.

  주요 구성요소의 라이선스 요약은 같은 폴더의 NOTICE 파일에 있습니다.
